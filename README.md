# Tour-Guide-Website

Building an interactive custom Tour Booking platform web application to handle user bookings and user logins

## What It Does
- **User Interface:** Responsive frontend built with HTML, CSS and vanilla JavaScript
- **Authentication and Security:** Secure user login system using `werkzeug.security` for password hashing
- **Data Storage:** Uses a PostgreSQL database to store user account data

## Tech Stack
-**Backend:** Python, Flask
-**Database:** PostgreSQL
-**Frontend:** HTML, CSS, JavaScript
